## 为什么保留两个接近的版本

Transpose P71 和 P66 的完整历史总耗时分别为 898.26 与 903.64 μs，差 5.38 μs，约为较快者的 0.60%。它们的 Case3 组织方式不同，保留两者有助于解释优化取舍。但这两次记录不是充分重复实验，不宣称 P71 在任何条件下都稳定领先。

其他题也保留有解释价值的对照，不过“两个数字接近”不足以证明并列最佳。尤其 Concat P07 仍有未定位边界失败，Greater 部分版本的计时来自不同批次，均在对应页面明确说明。

完整性能摘录见 [measurements.json](../data/measurements.json)，已核对文件身份见 [packages.json](../data/packages.json)。这些本地历史结果不能替代[比赛榜单](../docs/results.md)。
