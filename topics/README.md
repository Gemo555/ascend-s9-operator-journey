# 赛题介绍

本次比赛的挑战性能赛题共五道。以下只介绍各题要求；我们的具体实现放在[赛题方案](../operators/README.md)。

## Concat

将多个输入张量沿指定维度拼接成一个输出张量。输入在拼接维上的长度可以不同，输出需要保持各输入的原有顺序和值。

## Greater

对两个支持广播的张量逐元素比较，计算 `x > y`，输出布尔结果。输入的类型、形状和广播方向会影响读取方式。

## IndexAdd

以 `self` 为初值，沿指定维度把 `source` 的切片加到 `index` 指定的位置。索引可以重复，同一输出位置可能被更新多次。

## Transpose

根据 `perm` 调整张量各维度的顺序。输出中的每个元素都来自输入中的对应位置，元素值不变。

## SquareSumV1

将输入逐元素平方，再沿指定轴求和，计算 `sum(x * x, axis, keep_dims)`。`keep_dims` 决定被归约的维度是否在输出中保留为长度 1。
