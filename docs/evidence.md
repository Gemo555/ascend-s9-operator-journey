# 证据与验证范围

## 三类数字分别记录

| 类型 | 本仓库的依据 | 可以支持的结论 |
|---|---|---|
| 比赛榜单快照 | 原始 JSON、采集时间、源站链接、SHA256 | 在该次采集时，各题名次/耗时与按积分汇总的名次 |
| 历史官方结果 | 开发记录保存的官方回包数值，例如 Concat P06 | 该历史版本当时的通过情况；不能覆盖更晚榜单 |
| 本地真卡历史实验 | 同一包完整五例、发布记录、计时摘要 | 对应输入和环境下的历史行为；不等同于赛事平台结果 |

原始快照见 [data/results.json 中的来源](../data/results.json)。`final_result` 当前为 null。来源文件里的 `sourceType` 是采集器自带说明；本次建仓没有取得新的官网在线回包。

## 可复算的完整运行

[measurements.json](../data/measurements.json)收录 14 次完整运行，每行保留五例及总和，使用十进制字符串保存原记录精度。

| 组别 | 版本与完整总耗时 / μs | 比较范围 |
|---|---|---|
| Concat 历史官方 | P06：323.30 | 旧官方记录 |
| Concat 当前候选 | P07：307.1855 | 用户确认的候选；与原始摘要核对 |
| Concat 同场 ABBA | P06：331.055 / 325.9165；P07：312.2255 / 307.2455 | 同场完整版本；P07 另有边界失败 |
| IndexAdd 同场 ABAB | P135：668.3845 / 658.722499；P151：650.883499 / 649.0425 | 两轮完整对照 |
| Transpose 收尾 | P66：903.64；P71：898.26 | 不同完整运行，接近但非充分重复实验 |
| Greater 历史完整包 | P33：489.34；P46：488.829 | 不同批次，不直接判断稳定优劣 |

本地计时沿用原评测扩展的 30 轮调用，排除辅助 Mul，按原顺序取目标记录的第 11–30 条，并保留原脚本的整数转换与中位数规则。不得混用 profiler 诊断轮、单次启动时间或不同候选的单例最小值。

## 包身份与来源

[packages.json](../data/packages.json)保存七个已定位 ZIP 的文件名、大小、SHA256、包内源码及 installer 的 SHA256。此次建仓重新读取本地 ZIP 计算身份，未执行安装程序。

[sources.json](../data/sources.json)保存所依据开发文档/结果摘要的工作空间相对位置、SHA256 和用途。原件仍在开发工作空间，仓库收录的是整理后的说明与计时摘录，未公开整套云端日志或原始 profiling 数据。因此读者可以复算公开数字、检查正文模型，但暂不能从本仓库独立重跑完整 NPU 工程。

Concat P07 另做了[当前包与冻结材料的逐文件比对](../data/concat-p07-audit.json)。这确认了分析所指的源码身份；已有边界失败仍需单独处理。

SHA256 只能确认拿到的是哪份文件，不证明源码一定正确、设备实验一定可复现，或某个 ZIP 就是最终上榜包。后者需要提交回执等材料。

## 本仓库检查了什么

运行 `python scripts/check_repository.py`：

1. 从快照五题前十重新求和，核对积分规则、所有获积分队伍的并列名次和当前展示。
2. 使用十进制运算复算每次完整五例总和，检查测量与包身份的来源引用。
3. 核对九篇正文内容 SHA256，并运行七个独立 Python 代码块。
4. 检查 Markdown 的仓库内文件链接和明显的本机路径泄漏。

这些检查不运行 NPU、不检查外部网站当前可达性，也不替代历史数据的原始逐行审计。正文中引用的既有正确性检查数量均属于当时记录，不是本次新测结果。
